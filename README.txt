# 🚀 TX System

Sistema de gestão desenvolvido para assistências técnicas, com foco em controle financeiro, ordens de serviço, estoque, clientes e indicadores de desempenho.

## 📌 Objetivo

O TX System nasceu para resolver problemas reais enfrentados por assistências técnicas, centralizando todas as operações em um único sistema moderno, simples e intuitivo.

---

## ✨ Funcionalidades

- 👥 Cadastro de clientes
- 📱 Cadastro de aparelhos
- 🔧 Ordens de Serviço (OS)
- 💰 Controle de caixa
- 📦 Controle de estoque
- 📈 Dashboard financeiro
- 📊 Relatórios
- 💳 Controle de pagamentos
- 🏪 Multiunidades (Quiosques)
- 🔐 Login de usuários
- 👨‍💼 Controle de permissões
- 🤖 Recursos com Inteligência Artificial

---
